# RetailX: End-to-End Data Engineering Project

A capstone-style project simulating a retail data platform — from raw ingestion to analytics-ready dashboards.

## Goals
- Ingest raw retail data (sales, inventory, customers)
- Build a full ETL/ELT pipeline (extraction → cleaning → transformation → loading)
- Orchestrate the pipeline (e.g. with Airflow)
- Load into a data warehouse
- Visualize insights with a BI dashboard
