# ETL: JSON to MySQL

Extract data from JSON source files, transform it into a clean tabular structure, and load it into a MySQL database.

## Goals
- Parse and flatten nested JSON
- Handle missing/inconsistent fields
- Design a MySQL schema for the cleaned data
- Load data using Python (e.g. `mysql-connector-python` or `SQLAlchemy`)
